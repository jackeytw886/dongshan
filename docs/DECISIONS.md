# Decisions — P013 長期決策紀錄

## 2026-10-21 motion-games（3D 體感遊戲與共用模組）

1. **放在子資料夾 `motion-games/`，不動根目錄 `index.html`。** 根目錄是冬山導覽的 GitHub Pages 入口（含 QR code 用途），新內容與其無關，獨立資料夾可避免影響既有網址。原檔名 `3d__9_optimized.html`、`3d__10_optimized.html` 改為 `3d-09-dragon-lion.html`、`3d-10-slow-jog.html`；原始版本保留在提交 `c05afa4`。
2. **三個共用模組都是單檔、免打包、UMD。** 使用者要求「之後直接嵌入就能用」，所以每個模組只要一個 `<script>`，不依賴建置工具；`motion-kit.js` 可在 Node 裡 `require` 做單元測試。
3. **偵測分級用 preset，遊戲自己的選項優先。** 五級：`quick`（展場、免校正）、`hands`（只用手）、`run`（跑步踏步）、`body`（全身，預設）、`advanced`（手指手勢）。同一個遊戲可讓使用者現場切換。
4. **進階手勢用 MediaPipe Holistic，而不是 Pose＋Hands 兩個模型同時跑。** 一個模型同時給骨架、雙手與臉，左右手再用「哪隻手腕最近」對應，避免兩模型對不上與重複運算。
5. **手指手勢用幾何規則＋多幀投票，不用訓練模型。** 不需要額外下載與資料集，可讀可調；6 幀中 4 幀一致且持續 0.22 秒才觸發。
6. **雙視窗用「同一個網址＋`?ds=`參數」開新視窗，舞台視窗當主控端。** 取代原本把整頁 HTML 寫進空白視窗（舞龍舞獅）或另寫一份小網頁（超慢跑）的做法；新遊戲不必重寫彈出視窗內容。所有操作經 `command()` 交給主控端，避免兩個視窗各算各的分數。
7. **字體大小用 CSS `zoom` 縮放整個資訊區。** 既有介面大量使用固定像素字級，改 rem 工程大；`zoom` 讓文字與按鈕等比放大，並依版面分開記住。
8. **介面圖示改為單一線條風格（`ui-icons.js`），移除 Font Awesome 與按鈕上的表情符號。** 3D 場景內的題目物件（例如寶特瓶）仍用表情符號當內容圖片，因為它們是題目本身。
